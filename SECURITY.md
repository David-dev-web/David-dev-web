# 🔐 Security Policy

## 🧩 Supported Versions

Only actively maintained versions receive security updates.
Older releases will not be checked or patched.

| Version | Status |
|-------- | ------------------ |
| 5.1.x | ✅ Supported |
| 5.0.x | ❌ No longer maintained |
| 4.0.x | ✅ Supported |
| < 4.0 | ❌ Unsupported |

---

## 🛠️ Reporting a Vulnerability

Security vulnerabilities are important – please report them responsibly and directly.

### 📬 How to Report

- **Do not** create a public issue.
- Instead, contact me via **GitHub Security Advisory** (Private Channel):
  👉 https://github.com/David-dev-web/David-dev-web/security/advisories

### ⏳ Response Time

- **24–72 Hours**: Initial acknowledgment
- **Up to 7 Days**: Assessment & Reproduction
- **Dependent on Severity**: Patch or Fix Plan

### ✔️ What You Can Expect

- Confidential handling of your report
- Transparent communication regarding progress
- Recognition in the Changelog, if desired

### ❌ What NOT to Do

- Do not post public exploits
- Do not publish unpatched details
- Do not test Proof-of-Concepts on live systems
